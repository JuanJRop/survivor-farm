# Pixel FX (Free)

Imported from Effect and FX Pixel All Free.zip. The 15 folders contain the original 64x64 pixel-art sheets. Each PNG is a colour-row sheet; the runtime slices cells on demand with point filtering and caches only the clips that are actually played.

The GIF preview files from the archive are not runtime assets. They are previews only and are intentionally omitted from the build.
